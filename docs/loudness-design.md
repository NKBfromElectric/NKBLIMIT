# Short-term LUFS — 2026-10-14

出力音声の **Short-term LUFS（直近3秒）** を計測する。ピークや単純RMSからの換算ではなく、左右別々にK-weightingを適用し、左右の二乗平均を加算する。3秒の矩形窓にゲートを適用せず、測定値へ追加の時間平滑化は行わない。UIの数値更新周期は測定窓と別の設定であり、5 Hzの表示更新でも音声側では毎サンプル計測する。

根拠は [ITU-R BS.1770-5 Annex 1](https://www.itu.int/dms_pubrec/itu-r/rec/bs/R-REC-BS.1770-5-202311-I!!PDF-E.pdf) の2段K-weighting、左右各1.0のチャンネル重み、および `-0.691 + 10 log10(power)` と、[EBU Tech 3341 §2.2](https://tech.ebu.ch/docs/tech/tech3341.pdf) のShort-term窓定義。Integrated LUFS、Momentary LUFS、LRAは今回のモジュールでは実装していない。**EBU Mode全体への適合や規格認証は主張しない。**

## フィルター

48 kHzではBS.1770-5 Table 1 / 2の係数をそのまま使用する。各段の伝達関数は `H(z) = (b0 + b1 z^-1 + b2 z^-2) / (1 + a1 z^-1 + a2 z^-2)`。

| 段 | b0 | b1 | b2 | a1 | a2 |
|---|---:|---:|---:|---:|---:|
| Shelf | 1.53512485958697 | -2.69169618940638 | 1.19839281085285 | -1.69065929318241 | 0.73248077421585 |
| High-pass | 1 | -2 | 1 | -1.99004745483398 | 0.99007225036621 |

他のサンプルレートでは、48 kHzの基準伝達関数を逆双一次変換してから、新しいレートで双一次変換する。`q = (1-z^-1)/(1+z^-1)` とすると `q_ref = (fs/48000) q_new`。基準の多項式 `c0 + c1 z^-1 + c2 z^-2` を次のように写像し、最後に分母の先頭係数で正規化する。

```text
k = fs / 48000
p0 = c0 + c1 + c2
p1 = 2 (c0 - c2) k
p2 = (c0 - c1 + c2) k^2
new = [p0+p1+p2, 2(p0-p2), p0-p1+p2]
```

これは基準のアナログ相当特性を保持する実装上の選択。サンプルレートによる双一次変換の周波数ワーピング差を含み、全レートで物理周波数ごとの応答が完全一致するとの主張はしない。8–384 kHzの有限レートを受け付け、不正レートは48 kHzへ戻す。44.1 / 48 / 88.2 / 96 / 192 kHzは専用試験で確認した。

## 窓、初期状態、実時間動作

- 窓長は `round(3 fs)` サンプル。計測開始／リセット直後は未取得の履歴をゼロとして扱い、常に3秒分のサンプル数で割る。`isReady()` はちょうど1窓取得後にtrueとなる。UIでは取得前の値を暫定値として表示できる。
- 左右の位相が逆でも相殺しない。音声サンプルは変更せず、メーター処理はリミッター出力に対して実行する。開始直後の遅延由来のゼロも取得サンプルとして数える。
- 正のエネルギーを二分木で再加算する。単純な移動和で、大音量が窓から抜けたあとに減算誤差が無音の残留表示になる問題を避ける。1サンプルあたりO(log N)、データ量に依存する一括再集計はない。
- リセットはO(1)。リセット後に連続して上書きされた履歴だけを有効とし、それより先の木をゼロとして参照する。事前確保した大きなバッファを音声コールバックでクリアしない。
- 木の容量は48 kHzで4 MiB、192 kHzで16 MiB。float / double両エンジンを準備すると、メーター合計はそれぞれ8 / 32 MiB。`prepare()`のみで確保し、`push()` / `reset()` / getterに確保やロックはない。
- NaN / Infはゼロ、有限の異常値は±1e6へ制限する。フィルター内部の絶対値1e-30未満をゼロへ落とし、denormalを避ける。無音と極端な低レベルは有限の-240 LUFSを返す。
- モジュールは単一音声スレッドで所有する。別スレッドへの値渡しはプロセッサー側のlock-free atomicを使用する。ホストが音声コールバックを停止している間は新しい測定サンプルも入らない。

`LoudnessTests.cpp` はJUCE非依存のC++20実行ファイル。MSVC Releaseで **3,339チェック合格**。48 kHzの独立したdirect-form-Iフィルター＋全窓再集計との比較、全5レートで40 / 997 / 4000 / 15000 Hzの独立した複素周波数応答との比較、997 Hzの校正、左右重み／逆相、3秒ちょうどの準備状態、開始時のゼロ履歴、音から無音への窓変化、強信号後の無音復帰、強信号後のリセットと窓一周、不正値、callback／reset／getter内のゼロ確保を確認した。
