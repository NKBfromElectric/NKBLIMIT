# 0.1.3 ポンピング・音量一致・品質検証

2026-10-14。0.1.2の音圧とCeiling追従を保ちながら、周期的なピークで背景音が短く上下する挙動を抑える調整を採用しました。平均エネルギー検出の時定数だけを25 msから50 msへ変更し、ピーク保持の100 ms、主リミッターの先読み、True Peak保護は維持しています。

以下は音の変化を比較する測定です。聴感上のポンピングが全条件で解消したことや、Ozoneとの音質同等性は確認していません。短い変動が減る一方、長い変動・戻り時間・アタックには残る代償を併記します。

## 背景音を分離した周期キックテスト

自作の30秒PCM24音源を、両実VST3で同じ条件で処理しました。右は一定の997 Hz、左は減衰する60 Hzキックと必要に応じ80 Hzの持続低音です。120/180 BPMの4区間から、状態が落ち着いた5秒を測定しました。

右の50 ms RMSを元の右チャンネルで割り、p95−p5を求めています。AMは997 Hzの両側に生じるキック周期の側帯波／キャリアから求めた変調率です。どちらも全体の音量合わせに依存しません。元音源の背景音のRMS変動は0 dB、側帯波は数値誤差の範囲でした。

| Input Gain・BPM・低音 | 背景音50 ms変動幅 0.1.2→0.1.3 | キック周期AM 0.1.2→0.1.3 |
|---|---:|---:|
| +7 dB・120・なし | 3.527→1.575 dB | 10.87→5.01% |
| +7 dB・120・あり | 4.193→1.455 dB | 12.60→4.27% |
| +7 dB・180・なし | 3.313→1.091 dB | 15.34→5.56% |
| +7 dB・180・あり | 3.351→1.963 dB | 13.06→5.72% |
| +16 dB・120・なし | 11.268→8.208 dB | 28.54→26.42% |
| +16 dB・120・あり | 11.362→6.473 dB | 29.71→21.93% |
| +16 dB・180・なし | 10.621→6.252 dB | 39.57→28.38% |
| +16 dB・180・あり | 10.355→6.214 dB | 37.14→27.56% |

全8条件で短い背景音の変動とキック周期AMが減りました。ただし400 msの変動幅は、+7 dB・180 BPM・低音ありで0.333→0.707 dB、+16 dB・120 BPM・低音なしで1.098→1.232 dBと悪化しています。すべての時間尺度で変動が減ったわけではありません。

分離DSPの周期テストでも、+16 dB・120 BPM・低音なしの「キック終了後、直前ゲインの0.5 dB以内へ戻る平均時間」は約89.6→249.5 msへ延びました。単発キックの回復だけでは判断できません。短い深いダッキングを抑える代わりに、条件によって尾を引く傾向が残っています。

実VST3の詳細は[周期テストJSON](verification-0.1.3/quality-pumping.json)と[要約CSV](verification-0.1.3/quality-pumping-summary.csv)、元音源の検査は[背景音の不変チェック](verification-0.1.3/quality-pumping-source-null.json)に保存しています。

## 独立TPと定常音・混合音

190–220秒の30秒を、独立NumPy畳み込みで192タップ・32相Kaiser再構成しました。人工的な切り出し端を含む値と、全タップが実音源内に収まる内部の値を別に確認し、この4ファイルでは一致しました。

| 192タップ・32相TP | 0.1.2 | 0.1.3 |
|---|---:|---:|
| +7 dB | −0.553805 dBTP | −0.553806 dBTP |
| +16 dB | −0.549715 dBTP | −0.549890 dBTP |

これは有限FIRのクロスチェックであり、TP規格適合認証や全入力の数学的上限ではありません。UI相当32タップ・8相と96タップ・16相も[TP検証JSON](verification-0.1.3/quality-independent-tp.json)に記録しています。

主DSPを48/384 kHzで分離検証しました。60/997 Hz定常音のTHD+Nとゲインリップルは今回の変更では同じでした。60+997 Hz二音の残差／キャリア比の最大増加は0.00318パーセントポイント、60+62 Hz二音のキャリア比の変化は追加0.0084 dB以内でした。静かな997 Hz背景に重ねた単発60 msキックの回復は約43.42→38.77 msでした。これらにはJUCE再構成フィルターとVSTホストを含みません。[分離DSP比較](verification-0.1.3/quality-native.json)に条件と値を保存しています。

ピーク保持を125/150 msに延ばす別候補は採用しませんでした。一部の周期テストの戻りは速くなりましたが、180 BPMのAMまたは50 ms変動幅が悪化し、実曲のアタックも追加で弱まりました。最終版はエネルギー50 ms・ピーク100 msです。
